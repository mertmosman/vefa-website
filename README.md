# 🏛️ Vefa Aile Danışma Merkezi - Web Sitesi

Vefa Aile Danışma Merkezi için geliştirilmiş kurumsal web sitesi projesi. Bu proje, merkezin hizmetlerini, uzmanlarını ve iletişim bilgilerini tanıtmak amacıyla hazırlanmıştır.

## 🎯 Projeye Genel Bakış

<img width="1837" height="1040" alt="Ekran görüntüsü 2026-01-12 184404" src="https://github.com/user-attachments/assets/e31acc26-5fd7-4de7-8439-21ee9156f854" />

Bu web sitesi, bir aile danışma merkezinin dijital dünyadaki yüzü olmayı hedefler. Kullanıcı dostu arayüzü ile ziyaretçilerin aradıkları bilgilere kolayca ulaşmasını sağlar. Proje tamamen statik HTML, CSS ve JavaScript kullanılarak oluşturulmuştur ve Bootstrap framework'ü ile mobil uyumlu (responsive) hale getirilmiştir.

## ✨ Özellikler

Site, bir kurumsal web sitesinde bulunması gereken tüm temel bölümleri içermektedir:

* 🏠 **Anasayfa:** Ziyaretçileri karşılayan, genel bilgilerin ve yönlendirmelerin bulunduğu vitrin sayfası.

* 🤝 **Hizmetlerimiz:** Sunulan danışmanlık hizmetlerinin listelendiği ana sayfa.
* <img width="1102" height="1040" alt="Ekran görüntüsü 2026-01-12 184745" src="https://github.com/user-attachments/assets/51341215-e4af-4125-9418-f16975e0c91a" />

* 🧑‍💼 **Uzmanlar:** Merkezde görev alan danışmanların ve uzmanların tanıtıldığı bölüm.
* ✍️ **Blog:** Bilgilendirici makalelerin, duyuruların ve haberlerin paylaşıldığı alan.
* 📞 **İletişim:** Adres bilgileri, harita, telefon numarası ve ziyaretçilerin mesaj gönderebileceği bir iletişim formu.

## 💻 Kullanılan Teknolojiler

Proje, modern web standartlarına uygun olarak aşağıdaki teknolojilerle kodlanmıştır:

* 📄 **HTML5:** Sayfa içeriğinin anlamsal iskeleti.
* 🎨 **CSS3:** Özel stiller, animasyonlar ve tasarımsal düzenlemeler.
* ⚡ **JavaScript (JS):** Sitedeki interaktif öğeler (slider, menü vb.) ve dinamik fonksiyonlar.
* 📱 **Bootstrap:** Hızlı ve kolay bir şekilde mobil uyumlu (responsive) tasarım oluşturmak için kullanılan popüler bir CSS framework'ü.

## 🚀 Kurulum ve Çalıştırma

Bu proje herhangi bir sunucu kurulumu veya derleme işlemi gerektirmez. Projeyi yerel bilgisayarınızda çalıştırmak için aşağıdaki adımları izleyebilirsiniz:

1.  Bu repository'yi (depoyu) bilgisayarınıza indirin veya klonlayın:
    ```bash
    git clone [https://github.com/](https://github.com/)[KULLANICI_ADINIZ]/[PROJE_ADINIZ].git
    ```
    *(Not: `[KULLANICI_ADINIZ]/[PROJE_ADINIZ]` kısmını kendi GitHub bilgilerinizle güncellemeyi unutmayın.)*

2.  İndirdiğiniz proje klasörünün içine gidin.

3.  `index.html` dosyasına çift tıklayarak projeyi varsayılan web tarayıcınızda açın.

### ⚠️ Önemli Not

Proje, Bootstrap gibi dış kütüphaneleri ve muhtemelen Google Fonts gibi servisleri CDN (Content Delivery Network) üzerinden çekmektedir. Bu nedenle, projenin stillerinin ve fonksiyonlarının beklendiği gibi çalışması için **aktif bir internet bağlantısı gerekmektedir.**
